A program/v1 entry for make.fun's "One Letter: Coffee or Tea" bounty. The program writes exactly one character to `/output/entry.txt` — **A**, for *coffee*: the top grade, the first choice, and the honest fuel of every deadline day. A judge model compares letters pairwise and picks the one that feels more vivid, funnier and truer.

## Run it

```sh
python3 main.py
```
